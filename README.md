# WebDesignProj
Repositório acadêmico de Web Design focado no desenvolvimento de interfaces front-end do zero. Contém aplicações práticas de estruturação semântica em HTML5, estilização avançada e layouts responsivos com CSS3 (Flexbox e Grid), além de manipulação de DOM, eventos e validação de formulários utilizando JavaScript puro, aplicando princípios de UI/UX.
